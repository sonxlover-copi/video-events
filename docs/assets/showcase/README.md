# Источник демонстрационных материалов

Файлы `option-a.*` и `option-b.*` — производные демонстрации Video Events на основе видео **Mike Bird, Traffic Flow In The Highway**, Pexels ID **2103099**.

- Страница автора и исходника: https://www.pexels.com/video/traffic-flow-in-the-highway-2103099/
- Условия использования: https://www.pexels.com/license/
- Дата проверки источника: 9 ноября 2026 года.
- Исходное изображение изменено: нанесены рамки, ID, признаки, линия, счётчики и панель событий.
- Автор исходной съёмки не заявляется участником или сторонником проекта Video Events.

Файлы `*-events.csv` содержат вывод программы на соответствующем фрагменте. GIF предназначены для просмотра в README, MP4 — для просмотра с более высоким качеством. Параметры и способ воспроизведения приведены в [описании демонстраций](../../showcase.md).
