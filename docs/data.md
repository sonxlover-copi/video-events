# Локальные данные

Большие архивы и производные видео не включены в репозиторий. Это сохраняет Git-клон небольшим и не распространяет копии датасета без проверки условий его использования.

## Источник

Описание UA-DETRAC, архивы изображений и аннотаций опубликованы на [странице проекта UA-DETRAC](https://sites.google.com/view/daweidu/projects/ua-detrac). Перед публикацией данных или производных материалов проверь действующие условия источника и требования к цитированию.

## Файлы для воспроизведения оценки

Оценка в README использует:

- последовательности `MVI_40201`, `MVI_40204` и `MVI_40141`;
- видеофайлы в `data/processed/ua_detrac/`;
- XML-аннотации в `data/raw/ua_detrac/selected/DETRAC-Train-Annotations-XML/`;
- модель `models/yolo11n.pt`.

Пути локальных архивов, использованные при разработке:

```text
data/raw/ua_detrac/DETRAC-Images.zip
data/raw/ua_detrac/DETRAC-Train-Annotations-XML.zip
```

Из архива изображений нужны кадры выбранных последовательностей. Для количественной оценки также нужны XML-аннотации. Подготовленные MP4 и результаты `count` должны лежать по путям из команды в корневом README. Архивы, распакованные кадры, видео, веса и результаты запусков игнорируются Git; не добавляй их принудительно без проверки лицензии и размера.

Для собственного видео исходный датасет не нужен: укажи путь к видео и собственный YAML в команде `video-events count`.
