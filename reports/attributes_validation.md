# Проверка цвета кузова и чтения номеров

Проверка выполнена 8 ноября 2026 года для версии 0.2.0. Исходный код новых режимов: [цвет и накопление признаков](../src/video_events/attributes.py), [детектор номера и OCR](../src/video_events/plates.py). Полный [протокол JSON](attributes_validation.json) содержит версии, SHA-256 моделей, результаты и условия запусков.

## Контрольное изображение

Использована [фотография из репозитория FastALPR](https://raw.githubusercontent.com/ankandrew/fast-alpr/master/assets/test_image.png). На основной машине визуально читается `5AU5341`; видимый кузов серый. Команда `read-plates` нашла номер и вернула тот же текст. Confidence OCR около 0.9998 — это выход модели на одном примере, а не измеренная точность распознавания.

После подготовки весов проверка повторена с запретом вызовов `urllib.request.urlopen`: распознавание успешно выполнилось из кеша без сетевых запросов.

## Полная связка модулей

Скрипт `run_attributes_demo.py` создаёт панорамирование этой фотографии: 96 кадров, 800×450, 12 FPS, длительность 8 с. Этот пример проверяет работу кода на контролируемом движении изображения и не считается независимой проверкой на реальном видеопотоке.

Выполнен настоящий проход YOLO11n → ByteTrack → цвет и OCR → геометрический счётчик:

| Проверка | Результат |
| --- | --- |
| Цвет основной машины | `gray` |
| Номер основной машины | `5AU5341` |

## Настоящее дорожное видео

Полностью обработан `MVI_40204` из UA-DETRAC: 1225 кадров, 960×540, 25 FPS, 49 с. Включены `--colors --plates`, интервал 10 кадров, минимальное число совпадающих чтений 2, OCR confidence от 0.85. YOLO11n работает на RTX 5060 Laptop GPU, детектор номера и OCR — на CPU Intel Core i7-13650HX.

- Получено 117 пересечений. Все базовые поля каждой строки событий совпали с запуском без признаков.
- При повторной оценке: TP 116, FP 1, FN 18, precision 0.991, recall 0.866, F1 0.924 — без изменения метрик счётчика.
- В итоговом каталоге 259 ID трекера. Это не число уникальных физических машин: смена ID создаёт новую запись.
- Цвет подтверждён для 63 ID: `gray` 43, `white` 16, `red` 3, `green` 1. Для 196 ID сохранён `unknown`, в том числе из-за размера рамок и недостатка согласованных наблюдений. Это число выданных оценок, а не число правильно определённых цветов: отдельной цветовой разметки нет.
- Подтверждённых номеров нет. На данном дальнем ракурсе нет основания заявлять успешное чтение номеров.
- Полный проход занял 29,220 с, около 41,924 кадра/с, включая декодирование, нейросети, подписи и H.264-кодирование. Инициализация признаков заняла ещё 0,110 с, загрузка YOLO — 0,023 с. Это один запуск, без статистического усреднения.

Результаты сохранены локально в `runs/attributes/ready-traffic/`. Предыдущий замер базового режима без признаков на этом клипе — 64,275 кадра/с; OCR и анализ цвета увеличивают нагрузку. Оба замера являются одиночными проходами, а не контролируемым многократным бенчмарком.

## Автоматические проверки

Все 35 тестов проходят. Проверены геометрия и метрики предыдущей версии, базовые цвета, неопределённые/маленькие рамки, ограничение частоты анализа, раздельные состояния ID, подтверждение и отмена подтверждения номера, несколько номеров в одной рамке, нормализация российских номеров, неверные символы, низкий confidence, отсутствие весов и малый размер номера.

Те же тесты выполнены в отдельном окружении с NumPy/OpenCV и без PyTorch/OCR-моделей. Проверено переключение обычной установки и extra `plates`, обработка неверных аргументов CLI и защита существующих выходных файлов от перезаписи. Ruff и проверка форматирования проходят. GitHub Actions настроен на оба набора проверок; запуск на GitHub произойдёт после отправки изменений.

Независимая точность цвета, OCR на российских номерах и устойчивость чтения на движущихся автомобилях ещё не измерены. Повторные чтения одного изображения показывают корректную интеграцию, но не заменяют такую оценку.
