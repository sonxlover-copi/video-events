# Архив экспериментов

JSON-файлы в этой папке сохраняют промежуточные сравнения разрешения, положения линии и порогов ByteTrack. Для текущих сводных результатов используй отчёты в родительской папке и подробный [разбор MVI_40201](../ua_detrac_mvi40201_baseline.md). Архивные JSON не являются отдельными оценками на независимых камерах.
